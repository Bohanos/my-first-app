# My First Expo App

A clean, modern cross-platform mobile application built with **React Native**, **Expo**, and **Expo Router**. Featuring custom tab navigation, authentication flows, and dynamic route protection.

---

## ✨ Features

* **Authentication Flow:** Secure login screen layout with structured form inputs.
* **Expo Router Navigation:** Seamless file-based routing supporting stack and bottom tab navigation.
* **Custom UI & Styling:** Styled card components and color schemes tailored for a polished mobile experience.

## 🚀 Getting Started

### Prerequisites

Make sure you have Node.js, npm, and the Expo CLI installed on your machine.

### Installation & Running

1. Clone the repository:

   ```bash
   git clone https://github.com//my-first-app.git
   ```

2. Navigate to the project directory:

   ```bash
   cd MyFirstApp
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npx expo start
   ```
